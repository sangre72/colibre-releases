# Colibre — releases

Binary releases only (no source). Colibre is a car media streaming app: a Windows PC streams your own media and radio to the car browser.

Download: see the [latest release](../../releases/latest). Each release lists the SHA256 of the installer; verify it before running.

- Trial: the current build runs as a free trial for 7 days of use (or 84 hours of active use, whichever comes first). Radio keeps working after the trial ends.
- Default install folder: `%LOCALAPPDATA%\Colibre`.
- Unsigned installer: Windows SmartScreen may show a warning. Click "More info" > "Run anyway" (추가 정보 > 실행). Verify the SHA256 first.
- Viewing/controlling the PC screen needs an NVIDIA GeForce graphics card. Intel and AMD graphics support will ship as soon as test hardware is available. The current version is based on NVIDIA graphics (radio and music playback are unaffected).
- Support: support@colibre.app
